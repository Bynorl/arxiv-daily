用于 PDF 分类和文本提取的快速 Rust 库。默认情况下，它会检测 PDF 是基于文本的还是扫描的，通过位置感知提取文本，并转换为干净的 Markdown（无需 OCR）。本机 Rust 和 CLI 消费者可以选择选择性 OCR。包括 Python、Node.js 和浏览器 WebAssembly 的绑定。由 Firecrawl 构建，可在 200 毫秒内本地处理基于文本的 PDF，为约 54% 不需要的 PDF 跳过昂贵的 OCR 服务。 - **智能分类** — 通过对内容流进行采样，在大约 10-50 毫秒内检测基于文本、扫描、基于图像或混合的 PDF。返回置信度分数 (0.0-1.0) 和每页 OCR 路由。 - **文本提取** — 通过字体信息、X/Y 坐标和自动多列阅读顺序进行位置感知提取。
